# Crud-Filmes 🎬

Bem-vindo ao projeto **CineCRUD**! Este é um sistema web desenvolvido em Django para o gerenciamento completo de filmes (Adicionar, Listar, Atualizar e Remover) com um design premium usando o tema Escuro.

## 🌟 Funcionalidades
- **CRUD Completo:** Controle total do acervo de filmes.
- **Busca por API (OMDB):** Preenchimento automático de informações ao buscar o título de um filme em inglês, como Título, Diretor, Ano, Categoria e a capa.
- **Divisão por Categorias:** Os filmes são exibidos divididos organizadamente em categorias na página inicial.
- **Upload de Capa Manual:** Além da API, você pode carregar imagens diretamente do seu computador.
